\# TCS 332 – Assignment 2: Practical Implementation



This repository contains the practical implementations for TCS 332 Assignment 2.



\## Practical 1: Netcat and Wireshark

\- Captured network traffic using Wireshark.

\- Tested TCP communication using Netcat.

\- Saved packet capture files and screenshots.



\## Practical 2: Blockchain and SPV

\- Implemented a basic blockchain.

\- Generated and validated blocks.

\- Demonstrated tampering detection.

\- Implemented Merkle Tree and SPV inclusion proof verification.



\## Practical 3: Proof of Work and Proof of Stake

\- Simulated Proof of Work mining.

\- Demonstrated mining difficulty.

\- Simulated Proof of Stake validator selection.

\- Compared the energy requirements of both consensus mechanisms.
